# Лабораторная работа №1 по курсу «Компьютерная графика»

**Тема:** Алгоритмы рисования линий, заполнения областей на растре и аффинные преобразования на плоскости

**Автор:** Барсукова Виолетта
**Группа:** 47
**Язык реализации:** C# (Windows Forms / WPF)
**Год:** 2025

---

## Цели работы

1. Изучение базовых алгоритмов рисования простых плоских геометрических фигур.
2. Изучение принципов создания анимационных изображений.
3. Получение навыков программирования графики и анимации.

---

## Постановка задачи

Разработать программу, обеспечивающую:

- **a)** ввод произвольного многоугольника и замкнутого маршрута движения, анимацию (движение) построенной фигуры вдоль маршрута;
- **b)** редактирование построенного маршрута движения путём «перетаскивания» вершин;
- **c)** вращение фигуры в процессе движения;
- **d)** вращение маршрута движения.

---

## Реализованный функционал

| № | Возможность | Баллы | Статус |
|---|-------------|:-----:|:------:|

| b | Редактирование маршрута перетаскиванием вершин | 5 | ✅ |
| c | Вращение фигуры во время движения | 5 | ✅ |
| d | Вращение маршрута движения | 5 | ✅ |

## Используемые технологии и алгоритмы

- **Платформа:** .NET (C#)
- **GUI:** Windows Forms (GDI+) / WPF
- **Среда разработки:** Visual Studio 2022

### Алгоритмы

- **Растровый алгоритм Брезенхэма** — для построения отрезков прямых.
- **Алгоритм заливки с затравкой (по границе)** — для заполнения многоугольника.
- **Аффинные преобразования на плоскости:**
  - перенос (сдвиг) `T(dx, dy)`;
  - поворот `R(φ)` относительно заданной точки.
