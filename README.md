Лабораторная работа № 1 по курсу «Компьютерная графика»
"Алгоритмы рисования линий, заполнения областей на растре и аффинные преобразования на плоскости"
Цели работы:
1.  Изучение базовых алгоритмов рисования простых плоских геометрических фигур.
2.  Изучение принципов создания анимационных изображений.
3.  Получение навыков программирования графики и анимации.
Постановка задачи:
Разработать программу, обеспечивающую: 
a)  ввод произвольного многоугольника и замкнутого маршрута движения, анимацию (движение) построенной фигуры вдоль маршрута (5б.);
b)  редактирование построенного маршрута движения путем «перетаскивания» вершин (5б.);
c)  вращение фигуры в процессе движения (5 б.).
d)  вращение маршрута движения (5 б.)


Оценка лабораторной работы:
1.  Самостоятельно подготовленная программа оценивается из 100% максимально возможного рейтинга (25 баллов).
2.  Программа, подготовленная в группе из 2-х участников, оценивается из 50% максимально возможного рейтинга для каждого из участников (12 баллов).
